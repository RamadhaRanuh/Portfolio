## Question

What do strong AI/ML engineer portfolios look like today (structure, typography, color, motion, project presentation, hero treatments), and which patterns make one feel elegant without bloat? Collect 8-12 concrete exemplars with what to borrow and what to avoid, and surface any conventions a recruiter skimming for 60 seconds expects.

## Resolution

## Resolution

Strong AI/ML engineer sites win on restraint: a sentence-led hero, one column, one type family, a real photo, evidence thumbnails per project, and almost no motion. None of the 12 surveyed use particle or neural-net backgrounds. Full notes: https://github.com/RamadhaRanuh/Portfolio/blob/research/portfolio-conventions/.wayfinder/research/portfolio-conventions.md

**Exemplars** (borrow / avoid)
1. https://brittanychiang.com - experience-then-projects, stack tags on cards, one playful footer touch / avoid sticky-heavy polish
2. https://karpathy.ai - hand-written static HTML, one-line identity, thumbnail + repo link / avoid document-like look, no dark mode
3. https://rauno.me - confident manifesto hero / avoid hiding projects behind nav
4. https://leerob.com - rules and whitespace as ornament / too plain alone
5. https://thesephist.com - personal voice, short bio / no per-project evidence
6. https://sebastianraschka.com - role plus proof up top, theme toggle / nav sprawl
7. https://lilianweng.github.io - static Hugo baseline / nothing about the person up front
8. https://joshwcomeau.com - personality via copy and photo, good theme toggle / heavy interactive stack
9. https://colah.github.io - group by theme, venue credit line (useful for the ICCSCI paper) / blog-first IA
10. https://maggieappleton.com - humble one-sentence role hero, image cards / garden IA
11. https://www.paco.me - single page, few blocks / little visual evidence
12. https://eugeneyan.com - "Start Here", counts as credibility / long text archives

**Recruiter expectations** (secondary sources, directional): 30-90 second skim; first screen must say who, role, and one proof point; 3-5 polished projects beat many; each project shows problem, decision, result; conventional contents are bio, photo, projects, experience, links, contact, current CV. Quoted survey percentages in those posts were not verified and should not be reused.

**Implications**: supports static/no-build, editorial single column, light/dark toggle; hero should be sentence-led with the real headshot; flagship cards need image/GIF plus 1-2 hard numbers; skip particles, typing animation, blog IA. Caveat: layout details come from coarse page fetches, so verify visually before copying.
